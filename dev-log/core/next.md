# 首轮内核完成后的继续方向

P2–P6已经由K14–K33逐节提供完整实现和带敲正文：异常、内存、用户进程、FD、管道、VirtIO、同步日志、等待队列、异步提交/完成，以及真实用户shell。自己的day2目录继续从03写起，不需要切换成成品工程；每个停点都可以独立重建，图形支线继续自由暂停。

[K33](33-shell-pipeline.md)将用户分配、RAM文件、设备请求、等待切换和读回串成一个实际工作流。下一项必修收尾是把[L01–L08](../linux/README.md)在个人Linux上真实运行：本轮SSH255，不能把完整源码或Mac拒绝分支当作Linux成功。环境与证据边界见[验证记录](../../docs/verification.md)。

后续内核扩展可以从设备中断完成、COW、线程与同步、图形用户TTY或更完整文件系统中选择一项；当前没有把这些列为已经实现。WebUI先做宿主网关，开发板确定后再移植CPU与设备，AiriBoot保持独立预算。具体机制对应关系见[知识地图](../../docs/knowledge-map.md)。
