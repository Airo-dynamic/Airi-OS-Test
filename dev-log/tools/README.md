# 作者工具：重建、固定来源和保存位置

串口和Linux主线不依赖这些工具才能继续异常与内存管理。参考工程已经提供它们用于查阅；若要逐字写完作者工具，从L01后的源码继续三个独立检查点。

- [T01 · 从前置关系重建源码](01-reconstruction.md)：先固定章节资料，按依赖应用write/append，只向新目录写入。
- [T02 · 固定导出来源并保护快照](02-snapshots.md)：分别定位main/gui身份，用固定输入重建，完整构造后交接HISTORY。
- [T03 · 核对内容并记录位置](03-check-and-progress.md)：接入导航与学习命令，保留独立进度，完整演示目录保护和失败。

三节都不要求完成GUI。合并GUI分支后，同一工具从额外清单读取它的节点；没有GUI时，主线清单与运行目标保持独立。
