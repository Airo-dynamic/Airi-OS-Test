# 作者工具：重建、固定来源和保存位置

前面的课程每次改一组文件，后面的参考版本却已包含很多阶段。直接复制最新实现会丢失“当前起点是什么”的关系。这组作者工具把正文中的编辑变成可执行的重建配方：先从前置闭合得到文件，再固定资料来源，最后把核对和位置记录接回命令入口。串口和 Linux 主线不依赖这些工具才能继续异常与内存管理；参考工程已经提供它们用于查阅，若要逐字写完作者工具，从 L01 后的源码继续四个独立检查点。

- [T01 · 从前置关系重建源码](01-reconstruction.md)：先固定章节资料，按依赖应用写入、追加与精确替换，只向新目录写入。
- [T02 · 固定导出来源并保护快照](02-snapshots.md)：分别定位main/gui身份，用固定输入重建，完整构造后交接HISTORY。
- [T03 · 核对内容并记录位置](03-check-and-progress.md)：接入导航与学习命令，保留独立进度，完整演示目录保护和失败。

四节都不要求完成GUI。合并GUI分支后，同一工具从额外清单读取它的节点；没有GUI时，主线清单与运行目标保持独立。

- [T04 · 精确替换已有窗口](04-exact-edits.md)：从唯一旧文本定位新修改，拒绝缺失、歧义与整章半成功，保持旧检查点。

重建成功只证明正文与源码对应，运行成功只证明该次环境中的行为；它们都不能替代正文是否帮助读者理解的判断。
